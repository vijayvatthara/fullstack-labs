JavaScript Output Methods

Experiment 6(b)

1. console.log()

Displays output in the browser Developer Console.

2. alert()

Displays output in a browser alert dialog.

3. innerHTML

Displays output inside an HTML element.

Output will appear here.

4. document.write()

Writes content directly to the document.

Note: document.write() is demonstrated here for the lab requirement. It is generally avoided in modern dynamic web applications.

Output Methods Summary

Method Output Location
console.log() Browser Console
alert() Alert Dialog
innerHTML HTML Element
document.write() Document/Page
