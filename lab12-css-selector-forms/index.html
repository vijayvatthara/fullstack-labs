Selector Summary

Selector Type Example Purpose
Element p Selects all paragraph elements
ID #special-text Selects an element by ID
Class .highlight Selects elements by class
Descendant .container p Selects p elements inside container
Child .container > p Selects direct child p elements
Pseudo-class a:hover Applies style when link is hovered
Pseudo-element p::before Inserts content before an element
Attribute input[type="text"] Selects elements based on attributes
