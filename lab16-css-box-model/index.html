CSS Box Model

Content, Padding, Border and Margin

CSS Box Model Demonstration

Every HTML element can be represented as a rectangular box. The CSS Box Model consists of Content, Padding, Border and Margin.

Margin
Content

1. Content

This area represents the Content.

Content is the actual text or other information inside an HTML element.

2. Padding

Content

Padding is the space between the content and the border.

3. Border

Content

Border surrounds the content and padding.

4. Margin

Content

Margin creates space outside the border of an element.

Box Model Summary

Component Meaning
Content Actual text or element content
Padding Space between content and border
Border Line surrounding content and padding
Margin Space outside the border
