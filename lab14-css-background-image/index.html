Background image positioned halfway down the page

Background Image Demonstration

This page demonstrates how CSS can position a background image halfway down the page and keep it fixed while the user scrolls.

Scroll down the page and observe the background image. The content moves while the background remains fixed.

CSS Properties Used

  • background-image: Specifies the image used as the background.
  • background-position: Places the image at the required position.
  • background-attachment: Keeps the background fixed during scrolling.
  • background-size: Controls the size of the background image.

Scroll Test

Keep scrolling down. The background image should stay fixed while the page content continues to move.

This demonstrates the effect of:

background-attachment: fixed;

Result

The background image is positioned approximately halfway down the page and remains fixed when scrolling.
